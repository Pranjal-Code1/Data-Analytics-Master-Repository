# 🎮 Tic-Tac-Toe App (NumPy + Streamlit)

An interactive Tic-Tac-Toe web application built using **Python**, **NumPy** for game logic and matrix state management, and **Streamlit** for the user interface.

---

## 🚀 Features
- **NumPy Matrix State:** The 3x3 game board is managed using a NumPy array, with row, column, and diagonal sums checking for wins.
- **Interactive UI:** Built using Streamlit buttons for seamless browser play.
- **State Management:** Uses Streamlit session state to keep track of turns, moves, and game status.
